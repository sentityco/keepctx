Keep one context.
Every session, every AI, every teammate.

What your AI learns about a project shouldn't die with the session. KeepCTX gives your project one file where your AI writes down what it learns, and reads it back at the start of every session — in any tool, for everyone on the team.

Stop re-explaining the same thing

Every session, you re-explain how to log in to your servers, where the logs live, and what was decided last week. Every next session, it's forgotten. The fix isn't a bigger context window — it's automatically recording as the AI learns, in a place the next session reads automatically.

Every AI shares it

Claude, Codex and any agent that reads AGENTS.md reads the same file. Switch tools and nothing is lost.

Nothing to install for your team

It's a Markdown file in your repo, with its rules at the top. Teammates and their agents just pull.

In git, next to your code

History, review and revert work like everything else. A bad change is one revert away.

Simple and open

One command to set up. Open source. Uninstalling is deleting KEEPCTX.md.

How it works

keepctx init creates KEEPCTX.md and adds a short pointer to AGENTS.md. Your AI reads the file at the start of every session and adds to it as it learns — one fact per line. It tells you when it has read the file, and whenever it adds to it:

KeepCTX: KEEPCTX.md read (24 facts)
KeepCTX: added — storage: SQLite

## Facts
- **logs.location** — Splunk, index app_prod. Not CloudWatch.
- **prod.access** — SSO, then the bastion host. Never direct SSH.
- **storage** — SQLite: one file to back up, no database server to run
- **rejected.postgres** — a server to operate for a few megabytes of text

What goes in it

Whatever your AI judges worth keeping. A wide net: not just how things run, but what's being built and why. Never secrets, never what you put off the record.

Not just code. Investing, a book, a business — anything you keep re-explaining to an AI.

Quickstart

Python 3.9 or newer, no dependencies.

curl -fsSL https://keepctx.com/install.sh | sh
cd ~/work/your-project
keepctx init

# optional: commit KEEPCTX.md so teammates and their AI agents see and update the context too
git add KEEPCTX.md AGENTS.md && git commit -m "Add KeepCTX"

Then start a new AI session. That's all — there are no other commands.
